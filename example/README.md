# resizable_panel_group example

Runnable example app for `resizable_panel_group`.

## Run

```sh
fvm install
fvm flutter pub get
fvm flutter run
```

## What it shows

- landscape panel resizing
- portrait panel resizing
- nested vertical panel groups
- custom handle styling

The app switches automatically between landscape and portrait examples based on
available width, so you do not need to manually rotate the device just to make
the demo interactive.
